# Awesome Terminal Apps [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> Curated terminal/CLI apps for Windows — games, music tools, and creative apps.

Apps are classified by **Windows compatibility** so you know what runs natively:

- **Native** - Prebuilt Windows .exe or .zip with zero dependencies
- **MSYS2** - Needs MSYS2/MinGW to compile (ncurses-based)
- **Cross-platform** - Rust/Go/C++ with cross-platform builds
- **Python** - Python-based apps
- **Web** - Playable in browser or over SSH

## Installer

Install apps with one command using the PowerShell installer:

```powershell
# List all apps
.\scripts\install.ps1 list

# Filter by tier
.\scripts\install.ps1 list --tier native

# Filter by category
.\scripts\install.ps1 list --category roguelike

# Install an app
.\scripts\install.ps1 install nethack

# Install all native apps
.\scripts\install.ps1 install --all --tier native

# Remove an app
.\scripts\install.ps1 remove nethack

# Update installed apps
.\scripts\install.ps1 update

# Set custom install path (auto-detects non-C: drive by default)
.\scripts\install.ps1 config -AppsDir D:\my\apps

# Check current config
.\scripts\install.ps1 config
```

Apps are installed to the first non-C: drive by default (e.g. `D:\apps\terminal`). Falls back to `%USERPROFILE%\apps\terminal` if only C: exists.
